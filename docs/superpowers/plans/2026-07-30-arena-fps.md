# Arena FPS Low-Poly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menambahkan mini-game FPS low-poly 3D bernama `arena-fps` sebagai game ke-9 tanpa merusak delapan game Canvas 2D.

**Architecture:** Three.js hanya dimuat lewat dynamic import saat `arena-fps` dipilih. Gameplay deterministik dipisah menjadi modul pure TypeScript, sedangkan `FpsEngine` mengelola renderer, input, AI, HUD, lifecycle, dan callback `GameEngine`.

**Tech Stack:** React 19, TypeScript strict, Three.js, Vite, Vitest, Canvas/WebGL, Tailwind CSS v4.

## Global Constraints

- FPS memakai satu arena industri 16:9 dengan variasi kontainer, spawn, lighting, dan kabut dari seed.
- Maksimum 12 musuh aktif; target 30 FPS mobile menengah dan 60 FPS desktop.
- Musuh: drone, robot cepat, turret, tentara fiksi, zombie tanpa gore; boss setiap 5 wave.
- Senjata: pistol, assault rifle, shotgun; tembak dan reload manual; senjata dapat diganti.
- Pemain memakai 5 nyawa; satu serangan mengurangi satu nyawa dan memberi kebal 1 detik.
- Tidak memakai texture besar, model eksternal, gore, backend, atau penyimpanan progres.
- Desktop dan mobile wajib playable; `prefers-reduced-motion` wajib dihormati.
- `arena-fps` harus kompatibel dengan free play, roulette, dan Daily Gauntlet 45 detik.
